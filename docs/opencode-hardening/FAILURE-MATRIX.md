Status: real OpenCode `1.18.18` Phase 1–9 validation snapshot plus the separately
contract-tested V2 BLOCKER 0 core-discovery/session scope on 2026-08-28. This
does not claim complete V2 parity or a 24-hour soak. Failure attribution is
indexed in `docs/opencode-hardening/UPSTREAM-ISSUES.md`.
