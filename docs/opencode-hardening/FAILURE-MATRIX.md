# OpenCode hardening failure matrix

Status: final independent verification snapshot on 2026-08-27. The approved legacy P0
scope is complete. V2 capabilities remain disabled unless separately contract-tested.

| Failure | Expected behavior | Deterministic test / status |
| --- | --- | --- |
| POST accepted, response lost | One attempt; retain the same durable operation as unknown; reconcile by an exact receipt without duplicating the user message | `packages/server/test/opencodeReliabilityE2E.test.ts` — `accepted prompt with a lost response is durably unknown and sent once`; `response-lost prompt reconciles by operation receipt without a second message` |
| Session create accepted, response lost | Keep the canonical shell and original operation; recover only by exact operation receipt; never create a second backend session | `packages/server/test/opencodeReliabilityE2E.test.ts` — `response-lost create recovers its backend id from an exact operation receipt` |
| Mutation socket loss or deadline | Never generically replay POST/DELETE; return unknown after one request | `packages/backend-opencode/test/transportFaults.test.ts` — `POST accepted then closed is one attempt with an unknown outcome`; `mutation deadline is unknown after one attempt` |
| SSE drops a permission/question | Pull identified pending state and append one durable request | `packages/server/test/opencodeReliabilityE2E.test.ts` — `missed permission is pulled after disconnect and answered once`; `missed question is pulled after disconnect and answered once` |
| Permission arrives by SSE, pull, then SSE replay | Normalize every channel to the same entity/revision and retain one logical request | `packages/backend-opencode/test/reconciliation.test.ts` — `SSE and pull claim one semantic fact through SessionStore ingestion` |
| Complete pending list still contains a request after an unknown reply | Do not infer non-application from completeness alone; require explicit protocol-proven operation evidence | `packages/server/test/mutationOutcome.test.ts` — `complete pending data alone cannot prove an unknown response was not applied`; `explicit protocol evidence proves an unknown permission reply was not applied` |
| OpenCode crashes during an incomplete tool turn | Do not replay the prompt or invent completion; retain explicit unknown unless authoritative evidence proves interrupted/completed | `packages/server/test/opencodeReliabilityE2E.test.ts` — `backend hard death leaves an incomplete tool turn truthful across endpoint restart` |
| Reconnect races a persisted queue worker | Reconcile first; preserve the reservation/FIFO; dispatch once only after an authoritative idle result | `packages/server/test/opencodeReliabilityE2E.test.ts` — `queued follow-up survives disconnect and store restart, then dispatches once`; `packages/server/test/mutationOutcome.test.ts` — `unknown queue admission retains and blocks the FIFO reservation` |
| Two idle sends race | Admit one operation and durably queue the loser | `packages/server/test/delivery.test.ts` — `two concurrent idle sends admit once and durably queue the loser` |
| First access sees an idle persisted projection but upstream is running | First materialization reconciles before admission and restores working state | `packages/server/test/runtimeReconciliation.test.ts` — `first materialization reconciles an idle persisted session before admission` |
| Snapshot ingestion fails after its first event | Roll back every artifact, checkpoint, canonical event, and cursor; replay the complete snapshot exactly once | `packages/session/test/runtimeOperations.test.ts` — `whole snapshot transaction replays every artifact after an injected rollback`; `packages/server/test/runtimeReconciliation.test.ts` — `whole snapshot ingestion rolls back every artifact and cursor on an injected failure` |
| Config changes while an owned runtime is busy | Leave the batch pending and perform no write/restart until fresh authoritative safe-idle evidence exists | `packages/server/test/opencodeReliabilityE2E.test.ts` — `config apply waits for safe idle and restarts only an owned local target`; `stale idle projection cannot authorize config restart while upstream is running`; `packages/server/test/runtimePoolLifecycle.test.ts` — `busy runtime defers config apply and keeps the restart batch pending` |
| Config safety check races a new admission | Fence admission before checking safe-idle and hold the barrier through write, replacement, and reconciliation | `packages/server/test/runtimePoolLifecycle.test.ts` — `config safety check fences a racing admission through write and restart` |
| Pending config restart is overtaken by natural backend death after the complete config batch is durable | Serialize generation installation with the config transaction; perform one lock-owned restart after the write and let the queued natural refresh observe that live successor without another destructive restart | `packages/server/test/opencodeReliabilityE2E.test.ts` — `natural replacement before the first config write is interlocked until the owned restart loads the applied config` |
| Natural backend replacement occurs after safe-idle reconciliation but before the first config write | Keep the natural refresh queued behind safety/write/restart/reconciliation; clear the batch only after the lock-owned successor loads the new config | `packages/server/test/opencodeReliabilityE2E.test.ts` — `natural replacement before the first config write is interlocked until the owned restart loads the applied config`; `packages/server/test/runtimePoolLifecycle.test.ts` — `unproven generation drift fails closed and keeps the captured restart batch pending` |
| Shared/borrowed daemon changes URL or credentials while sessions are active | Rediscover/rebind HTTP and SSE together, fence stale callbacks, reconcile both sessions, and never stop the daemon | `packages/backend-opencode/test/runtimeLifecycle.test.ts` — `borrowed daemon rotation rebinds public HTTP and SSE for two active sessions without stopping it`; `runtime discards late old-generation callbacks before translation` |
| Owned replacement fails after the old child stopped | Never reactivate the dead generation; a later endpoint request builds a fresh generation | `packages/backend-opencode/test/runtimeLifecycle.test.ts` — `failed replacement cannot reactivate the stopped generation` |
| PID file points at a reused PID | Verify start/executable/command identity and signal nothing on mismatch | `packages/backend-opencode/test/runtimeLifecycle.test.ts` — `PID reuse is rejected without signalling the unrelated process` |
| Local bind collides repeatedly | Stop each exact failed child, choose a fresh port, and leak nothing | `packages/backend-opencode/test/runtimeLifecycle.test.ts` — `three local bind collisions select fresh ports and leak no children` |
| Two Polyth servers use one data directory | Second writer fails closed before opening runtime mutation paths; kernel release permits a later owner | `packages/server/test/runtimePoolLifecycle.test.ts` — `canonical data directory lease fails closed for a second writer` |
| Unknown backend deletion survives restart | Keep a durable tombstone and never offer the binding for re-adoption | `packages/server/test/runtimeReconciliation.test.ts` — `backend listing never offers an active deletion tombstone for re-adoption` |
| Generic transport is constructed while legacy credential environment variables exist | Send no ambient credentials unless the endpoint/client explicitly resolves them | `packages/backend-opencode/test/transportFaults.test.ts` — `generic transport never inherits legacy environment credentials` |
| One-shot or multirun create/prompt loses its response | Use durable prepare/claim/settle and retain ambiguity without duplicate execution; do not issue a compatibility ensure after confirmed create | `packages/server/test/oneshot.test.ts` — `one-shot response loss retains one durable operation and never executes twice`; `packages/multirun/test/multirun.test.ts` — `multirun response loss retains one durable operation and never executes twice` |
| Old-generation or superseded-ordinal observation arrives after replacement | Reject it before translation or SQLite claim; never regress checkpoints, cursor, attention, or projection | `packages/backend-opencode/test/reconciliation.test.ts` — `stale generations are discarded before translation mutates state`; `packages/backend-opencode/test/runtimeLifecycle.test.ts` — `runtime rejects stale generation bindings before protocol I/O`; `packages/session/test/runtimeOperations.test.ts` — `observation claim, canonical events, checkpoint, and cursor are one durable transaction`; `reconciliation ordinals reject superseded completion` |
| Forked or imported session performs its first wire | Reconcile before admission while claiming copied/imported history without appending it twice | `packages/server/test/runtimeReconciliation.test.ts` — `fork and import first-wire reconciliation does not duplicate copied history` |
| Legacy terminal snapshot has no ordered revision, has an opaque numeric-looking ID, or is older than the durable status checkpoint | Keep the session unknown, retain the newer checkpoint, and block admission instead of treating state text or opaque identity as terminal authority | `packages/backend-opencode/test/reconciliation.test.ts` — `legacy terminal status requires a numeric comparable revision`; `packages/server/test/runtimeReconciliation.test.ts` — `idle snapshot without a comparable watermark remains unknown and blocks admission`; `equal status evidence is idempotent but a stale terminal revision cannot reopen admission` |
| Fork receipt is replayed as idle evidence after the child executes a mutation | Reject the stale causal shortcut; source and child operation ordinals are different domains | `packages/server/test/runtimeReconciliation.test.ts` — `a fork receipt cannot prove child idle after any child mutation` |
| Runtime facade is selected | Route REST/SSE and every V1 mutation through one lifecycle-owned transport and protocol adapter | `packages/backend-opencode/test/adapter.test.ts` exercises the facade through a real fake HTTP server and lifecycle; `packages/backend-opencode/test/runtimeLifecycle.test.ts` verifies HTTP/SSE rebinding and borrowed no-stop behavior. The fixed-client runtime facade and `{ client }` option are removed. |
